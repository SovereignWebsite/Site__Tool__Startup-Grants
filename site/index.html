Startup grants in Europe and the UK

Public startup grants and funding programmes, each written from the programme's own official page, with that link and the date checked. Where an official page does not state something, we leave it blank. Deadlines change, so always check the official page before you act.

      About the data

      The starting list of programme names and official links came from the public Notion database European Startup Grant Programs (2026 Edition). None of its descriptions or text was copied. Every entry was written from the official page it links to. The data is open for reuse as grants.json, described in the schema.
